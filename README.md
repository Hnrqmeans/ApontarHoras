# ApontarHoras

Apontamento de horas em projetos de P&D (evidência para a Lei do Bem). O app roda num servidor da empresa e a
equipe acessa pelo navegador (na rede ou pela VPN). Um responsável cadastra projetos e colaboradores e, no fim do
mês, confere e exporta as horas de todos.

- **Sem dependências:** só a biblioteca padrão do Python; o pacote para Windows leva o Python oficial junto e abre
  em máquina limpa.
- Estado: fundação pronta (login, papéis, cadastros, auditoria). Apontamento e exportação em andamento —
  ver [docs/ROADMAP.md](docs/ROADMAP.md).

Desenvolvimento e build: [docs/DESENVOLVEDOR.md](docs/DESENVOLVEDOR.md).
